============================

内容：5308 条中文语音，覆盖车队工程师与 spotter 的全部常用播报。

  应答 acknowledge          279   差距 timings              229
  损伤 damage_reporting     205   队列 frozen_order         204
  圈数 lap_counter          198   燃油 fuel                 182

音频：单声道 / 22050 Hz / 16-bit PCM，峰值 −1 dBFS


哪些保留英文（有意为之，不是漏做）
==================================

  车手名、弯角名 —— 中文车手也说原名
  车辆组别号     —— GT3、GT300、LMP2、DTM、Group C 这类专有编号
  超车辅助       —— DRS、KERS、push-to-pass 整个分类

这些文件夹不在包里，装上后自动播原来的英文。除了「中文车手本来就说英文」，
还有个实际原因：中文语音引擎念拉丁字母不可靠，实测 GTC 三个字母能念到 1.73 秒，
DRS 在句子里只占 0.25 秒（三个字母名至少要 0.5 秒）。与其念不清楚，不如用原音。


先选一种装法
============

  用法 A —— 原版 CrewChief（多数人选这个）
      工程师和 spotter 全部说中文，装的时候要删掉 numbers 文件夹。
      只有圈速、差距里的数字仍是英文。

  用法 B —— 自己编译的 CrewChief
      全部装上，数字也说中文。需要你有 Windows 开发环境。

两种装法的区别只在第 3、5、6 步。用法 A 已经能拿到 5170 条中文播报，
用法 B 多出来的是 numbers 那 138 条。


⚠ 为什么原版程序不能装 numbers
==============================

numbers 包会覆盖 numbers/0 到 numbers/99、numbers/point、numbers/hour 这些
英文包里已经有的文件夹，但它没有英文特有的 928 个合成件 —— 其中 599 个是
45point6 这类「数字point数字」，另外还有 point75、1_23（分_秒）等预录整段读音。

结果就是：圈速播报里整数部分念中文、小数部分念英文，变成
「四十五 point six」。所以原版程序必须把 voice/numbers/ 删掉。

根源是 CrewChief 的数字朗读规则写死在代码里，每种语言一个实现类
（NumberProcessing/NumberReader.cs 定义了 10 个抽象方法），上游自带
en / it / pt-br，没有中文。中文规则和这三种都不一样——「二」和「两」要
分场合、万是独立量级、「一分二十三秒四」的结构也不同——所以需要
NumberReaderZh.cs（294 行）加 NumberReaderFactory 里的一个分支。


安装步骤
========

1. 找到语音包目录，默认在：

       %LOCALAPPDATA%\CrewChiefV4\Sounds

   （地址栏直接粘贴上面这行即可打开）

2. 整个复制一份到别处，比如：

       D:\CrewChief_zh\Sounds

   不要直接改原目录 —— 出问题时你需要能退回去。

3. 把本压缩包里的 voice 文件夹合并进复制出来的目录，覆盖同名文件。

       用法 A：合并前先删掉压缩包里的 voice\numbers\ 整个文件夹
       用法 B：全部合并

4. 打开 CrewChief 属性页（Properties），搜索：

       Override default Sound Pack location

   填入第 2 步的路径：D:\CrewChief_zh\Sounds

5. 用法 B 追加：在语音包根目录新建或编辑

       D:\CrewChief_zh\Sounds\sound_pack_language.txt

   内容写一行：

       zh

   用法 A 不要建这个文件，保持原样。

6. 用法 A 追加：防止下载按钮把英文包盖回来。编辑

       D:\CrewChief_zh\Sounds\sound_pack_version_info.txt

   把里面的版本号改成一个很大的值，比如：

       9999

   原因见后面「关于自动更新」一节。用法 B 不需要这一步。

7. 确认工程师语音和 spotter 语音两个下拉框都是默认值。

   这一步很关键。CrewChief 在使用非默认工程师语音包时，会强制从基础包
   读取 spotter 和 radio_check（见 Audio/Sounds.cs 中
   prepareVoiceWithoutLoading 的实现）。一旦选了 Jerry 之类的替代语音，
   spotter 会退回英文。

8. 重启 CrewChief（Override 这个设置需要重启才生效）。


字幕显示成方块怎么办（可选）
============================

只有开了字幕覆盖层才需要看这一节，不开可以跳过。

本包每个语音文件夹里都带了 subtitles.csv，字幕文本是中文。覆盖层默认字体是
Microsoft Sans Serif（Overlay/OverlaySettings.cs），如果中文显示成方块，改字体：

    我的文档\CrewChiefV4\subtitle_overlay.json

找到 "fontName" 那一行，改成系统里有中文字形的字体：

    "fontName": "Microsoft YaHei",

工程师覆盖层是同一套设置，文件叫 crewchief_overlay.json，同样改法。

两个 json 都是 CrewChief 首次运行时自动生成的，找不到就先启动一次。改完重启
CrewChief 生效，不需要重新编译程序。


用法 B 需要的程序改动
=====================

源码改动在项目仓库：

    CrewChiefV4/NumberReaderZh.cs                        （新增，294 行）
    CrewChiefV4/NumberProcessing/NumberReaderFactory.cs  （+7 行）
    CrewChiefV4/CrewChiefV4.csproj                       （+1 行）

需要 Windows + Visual Studio / msbuild 自行编译，配置选 Release | x86。

启动后日志里应该出现：

    Using NumberReaderZh for soundPackLanguage zh

没有这行说明语言标记没读到，检查 sound_pack_language.txt 的位置和内容。


验证
====

- 启动时的无线电测试是中文
- 进游戏后有车贴近时的盲区提醒是中文
- 工程师播报是中文：旗语、圈数、燃油、轮胎、罚则、进站……
- 车手名、弯角名、GT3 这类组别号仍是英文 —— 正常，见前面「哪些保留英文」
- 用法 A：圈速里的数字仍是英文（「你的圈速是 one twenty-three point four」）
- 用法 B 额外：数字也是中文（「你的圈速是一分二十三秒四」）


卸载
====

把属性页里的 Override default Sound Pack location 清空，重启即可。
用法 B 还要把 sound_pack_language.txt 改回 en 或删掉。


关于自动更新
============

先说清楚：CrewChief 不会在后台静默覆盖你的语音包。它只是把主界面上的语音包
下载按钮点亮，要你自己点了才会下载覆盖。所以最坏情况是「哪天顺手点了绿按钮，
中文包被英文包盖掉」，不是开着开着就没了。

按钮亮不亮的判断是 latest > current（UserInterface/SoundPacks.cs 第 117 行）：

  current  读你语音包根目录的 sound_pack_version_info.txt
  latest   从上游 auto_update_data.xml 里按【语言】取

两种装法的处境不同：

  用法 B（语言标记 = zh）
      查 zh 段，上游没有这一段，取不到任何更新包，按钮永远是灰的。
      天然免疫，不用做额外操作。

  用法 A（没有语言标记）
      语言为空时代码按 en 查（UserInterface/MainWindow.cs 第 607 行），
      拿到的是真实的英文包版本号，上游一发新版按钮就会变绿。
      所以第 6 步要把 current 撑大到 9999。

⚠ 启动参数 -skip_updates 不管用。它只跳过程序本体的更新检查
（AutoUpdater.Start），语音包的 XML 照样下载和比对，别拿它当防线。


制作参数
========

  TTS      XTTS v2（Coqui），语言码 zh-cn
  音色     Bart，取自 crew-chief-autovoicepack 的 12 条干净片段（38.9 秒）
  语速     1.45x，实测约 188 毫秒/音节
  后处理   radio EQ 曲线
  术语     3 wide → 三辆并排，clear → 安全，inside/outside → 内线/外线
